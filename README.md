# llm-lab

LLM 애플리케이션 개발 학습 기록.
API 호출부터 RAG, 에이전트까지 직접 만들어보며 정리합니다.

## 목차

| 폴더 | 주제 | 상태 |
|---|---|---|
| [01-langchain-v1](./01-langchain-v1) | LangChain V1 기초 — 체인, 에이전트, RAG | 진행 중 |

## 환경

- Python 3.11
- 의존성은 각 폴더의 `requirements.txt` 참고

## 시작하기

```bash
git clone <this-repo>
cd llm-lab
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
cp .env.example .env        # API 키 입력
```
