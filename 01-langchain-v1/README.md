# 01. LangChain V1 기초

LangChain V1 문법으로 체인 · 에이전트 · RAG의 기본 구조를 익힌 실습 기록.

- 출처: [랭체인 Ver.1 무료 강의](https://www.youtube.com/watch?v=rb3ZYR_Q1po)
- 환경: Python 3.11 / langchain 1.x
- 기간: 2026.09 ~

## 실습

| 파일 | 내용 | 상태 |
|---|---|---|
| [01_basic_chain.py](./01_basic_chain.py) | 프롬프트 → 모델 → 파서 연결 | ⬜ |
| [02_agent.py](./02_agent.py) | 도구를 쓰는 에이전트 | ⬜ |
| [03_middleware.py](./03_middleware.py) | 요청 · 응답 중간 처리 | ⬜ |
| [04_guardrail.py](./04_guardrail.py) | 입출력 제약 걸기 | ⬜ |
| [05_rag.py](./05_rag.py) | 문서 검색 붙이기 | ⬜ |

## 실행

```bash
pip install -r requirements.txt
python 01_basic_chain.py
```
